# Источники

Условия проверены по официальным страницам источников **2026-10-21**. Перед расширением опроса перепроверяйте их.

| Источник | Метод | Покрытие за проход | Ограничения и атрибуция | Мин. интервал в приложении |
|---|---|---|---|---|
| Jobicy | `GET https://jobicy.com/api/jobs?count=100` | 1 страница до 100 из ленты за 7 дней (есть cursor) | автоматический проход не чаще раза в час; указывать Jobicy и ссылку на карточку | 6 ч |
| Remotive | `GET https://remotive.com/api/remote-jobs?limit=300` | всё, что отдаёт публичный API (задержка 24 ч) | ≤4 запросов в сутки, >2/мин блокируется; ссылка на Remotive обязательна; нельзя передавать в другие доски | 6 ч |
| Remote OK | `GET https://remoteok.com/api` | последние ~100 объявлений | ссылка на Remote OK и упоминание источника обязательны | 12 ч |
| Himalayas | `GET https://himalayas.app/jobs/api?limit=20&cursor=…` | 3 страницы × 20 (максимум API) из 6 000+ | данные обновляются раз в 24 ч; видимая атрибуция; кнопка отклика — `applicationLink`; не передавать в другие доски | 24 ч |
| Working Nomads | `GET https://www.workingnomads.com/api/exposed_jobs/` | последние несколько десятков | официальных лимитов не нашли; опрос не чаще 2 раз в сутки | 12 ч |
| We Work Remotely | RSS `remote-jobs.rss` | текущая первая страница ленты | публичный RSS; ссылка на исходную карточку | 12 ч |
| Хабр Карьера | RSS `vacancies/rss?page=N` | 2 страницы (~50 на страницу) с кратким описанием | публичный RSS; ссылка на исходную карточку | 12 ч |
| Greenhouse / Lever / Ashby | публичные Job Board API | полные доски выбранных компаний, до 25 компаний | 1 запрос на компанию в сутки, пауза между компаниями | 24 ч |

Пользователь может увеличить интервал, но не уменьшить ниже указанного.

## Исключённые источники

По умолчанию (встроено, удалить нельзя): `hh.ru`, `headhunter.ru`, `hh.kz`, `hh.uz`, `hh1.az`, `headhunter.ge`, `headhunter.kg`, `rabota.by`, `hhcdn.ru`, `hh.ua`. Правило действует на поддомены, редиректы (каждый шаг проверяется до запроса), параметры (`?url=…hh.ru…`), пути зеркал и ссылки внутри текста. Запись с таким происхождением не сохраняется, в импорте помечается `blocked`, внешняя ссылка не открывается.

## Что не подключено

hh.ru (запрещён), LinkedIn/Indeed/Glassdoor (нет разрешённого публичного API без входа), Telegram-каналы (нужен аккаунт). Новый источник добавляется только вместе с адаптером, тестом на фикстуре и проверкой условий.
