# Источники

Какие источники использовать, выбирает пользователь: в «Настройках» (раздел «Источники»), списком исключённых доменов или своими словами в «Дополнительных инструкциях для ИИ». По умолчанию приложение ничего не исключает.

Поиск строится из направлений профиля: из каждого включённого направления берутся главные фразы, и источники с поиском опрашиваются по ним постранично. Остальные источники читаются как ленты. Дубли между источниками объединяются (ID источника, канонический адрес, requisition ATS, осторожное сравнение компании, названия, локации и текста).

| Источник | Метод | Глубина за проход | Условия использования | Мин. интервал |
|---|---|---|---|---|
| Himalayas | `GET /jobs/api/search?q=…&page=N` и `GET /jobs/api?cursor=…` | поиск по всей базе по каждому направлению + свежая лента, до 24 страниц по 20 | видимая атрибуция; отклик — `applicationLink`; не передавать в другие доски | 24 ч |
| The Muse | `GET /api/public/jobs?category=…&page=N` | удалённые вакансии в близких категориях, до 10 страниц по 20 | без ключа до 500 запросов в час | 12 ч |
| Arbeitnow | `GET /api/job-board-api?page=N` | до 3 страниц по 300 | бесплатный публичный API без злоупотреблений; ссылка на Arbeitnow | 12 ч |
| Jobicy | `GET /api/v2/remote-jobs?count=…&tag=…` | лента до 100 + поиск по тегам направлений | не чаще раза в час; указывать Jobicy и ссылку на карточку | 6 ч |
| Remotive | `GET /api/remote-jobs?limit=300` и `?search=…` | вся публичная выдача + поиск; пауза 35 с между запросами | не больше 4 раз в сутки и 2 запросов в минуту; ссылка на Remotive | 6 ч |
| Remote OK | `GET /api` | последние ~100 объявлений | ссылка на Remote OK и упоминание источника | 12 ч |
| Working Nomads | `GET /api/exposed_jobs/` | последние объявления | официальных лимитов нет; не чаще 2 раз в сутки | 12 ч |
| We Work Remotely | RSS `remote-jobs.rss` | текущая лента | публичный RSS; ссылка на карточку | 12 ч |
| Хабр Карьера | RSS `vacancies/rss?page=N` и `?q=…` | новые вакансии + поиск по направлениям | публичный RSS; ссылка на карточку | 12 ч |
| hh.ru | официальный API `GET /vacancies?text=…&area=…&page=N` | поиск по направлениям и стране, до 100 на страницу, глубина до 2000 на запрос | с апреля 2026 нужен OAuth-токен: приложение, зарегистрированное на dev.hh.ru, и вход через аккаунт hh.ru (или токен приложения) | 6 ч |
| Adzuna | `GET /v1/api/jobs/{country}/search/{page}` | 19 стран, по 50 на страницу | бесплатный ключ разработчика (`app_id`, `app_key`); ссылка на Adzuna | 6 ч |
| Greenhouse / Lever / Ashby | публичные Job Board API | полные доски выбранных компаний, до 25 компаний | 1 запрос на компанию в сутки, пауза между компаниями | 24 ч |

Пользователь может увеличить интервал, но не уменьшить ниже указанного. Сервер поиска соблюдает те же ограничения.

## Доступы

hh.ru и Adzuna включаются только после того, как пользователь подключит доступ в «Настройках» и проверочный поиск пройдёт успешно. Токены и ключи хранятся зашифрованными в системном хранилище ключей и не попадают в журнал и экспорт.

## Исключения

Исключённый домен блокируется в любой форме: прямой адрес, поддомен, перенаправление (каждый шаг проверяется до запроса), параметр (`?url=…`), путь зеркала, ссылка в тексте объявления и в импортируемых файлах. Если в инструкциях названо семейство сервисов («hh.ru и связанные сервисы»), исключаются все его домены.

## Не подключено

LinkedIn, Indeed и Glassdoor не дают разрешённого публичного API без входа; Telegram-каналы требуют аккаунта. Новый источник добавляется вместе с адаптером, тестом на фикстуре и проверкой условий использования.
