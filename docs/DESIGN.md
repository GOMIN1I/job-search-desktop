# Дизайн: система «Маркер»

Приложение делает то же, что человек с распечаткой вакансии и тремя маркерами: проводит по строке, которая подходит, по той, что надо уточнить, и по той, что не подходит. Отсюда весь визуальный язык: светлая «бумага», графитовые «чернила», один сосново-зелёный цвет для действий и три маркера для выводов. Маркер появляется только там, где есть вывод или цитата, а не для украшения.

Макеты и библиотека компонентов: [Figma, «Job Search Desktop — Маркер»](https://www.figma.com/design/RsmpL7KRHLtJZ7ZPiGgn6Y). Страницы Foundations (переменные Light/Dark, текстовые стили), Components (кнопки, вердикты, строка доказательства, карточка модели), Screens (первый запуск, «Сегодня» с живым поиском, карточка вакансии).

## Правила

- **Вердикт = маркер + значок + слово:** «✓ Подходит», «? Уточнить», «✕ Не подходит». Цвет никогда не единственный носитель смысла.
- **Цитаты из объявления** подсвечиваются мягким маркером того же цвета, что и вывод по условию: видно, откуда взялся вывод.
- **Движение объясняет, что произошло:** маркер «проводится» слева направо при появлении вывода; полосы источников показывают живой ход поиска (ждёт, читает, найдено N, нет ответа); подсказка по экрану подсвечивает кольцом нужную кнопку. Других анимаций нет. `prefers-reduced-motion` отключает все переходы, вывод показывается сразу.
- Одна сосновая кнопка на экран, остальные спокойные. Модальные окна с ловушкой фокуса, Esc и подписью; тосты в `aria-live`.
- При ширине меньше 1000 px боковая панель сворачивается до иконок с `aria-label`.

## Иконка

`build/icon.svg`: сосновый квадрат со скруглением, на нём наклонённая белая карточка объявления, по одной строке проведена лаймовая полоса маркера с галочкой. Для 16–48 px используется упрощённый вариант `build/icon-small.svg` (без мелких строк), чтобы иконка читалась в трее Windows и в Dock. Растры и `icon.ico` строятся командой `npm run icon` (Electron offscreen рендер).

## Сайт и ролик

Сайт (`site/`) и ролик (`film/`) говорят тем же языком: бумага, чернила, три маркера, Golos Text. Интерактивное объявление на первом экране сайта пересчитывает вердикт при переключении условия «Без звонков». Ролик снят на реальных записях экрана; каждая запись подписана («настоящий поиск, ускорено», «демо-данные»).

## Скриншоты

`docs/screenshots/` создаются автоматически из настоящего окна Electron на синтетических данных (`npm run e2e`, `E2E_LANG=ru|en`): первый запуск, подсказки, «Сегодня», подборка, карточка, отклик, доска, профиль, вкладки настроек, три размера окна, тёмная тема.
