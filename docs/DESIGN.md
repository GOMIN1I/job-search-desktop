# Дизайн

Сдержанная рабочая программа: данные читаются раньше декора. Светлая нейтральная основа, графитовый текст, один сине-зелёный акцент, системная тёмная тема, системные шрифты с хорошей кириллицей (SF Pro / Segoe UI Variable / Roboto).

## Токены (`src/renderer/styles.css`)

| Токен | Светлая | Тёмная | Назначение |
|---|---|---|---|
| `--bg` | `#f6f7f7` | `#121516` | фон окна |
| `--surface` | `#ffffff` | `#191d1f` | карточки, панели |
| `--text` | `#1d2326` | `#e6eaeb` | основной текст (графит) |
| `--text-2` / `--text-3` | `#4f5a5f` / `#7c878c` | `#aab4b8` / `#7f8a8f` | вторичный текст |
| `--accent` | `#0f766e` | `#38b2a6` | единственный акцент |
| `--ok` / `--warn` / `--bad` | `#18794e` / `#9a5b00` / `#b42318` | светлее | статусы — всегда вместе с иконкой и словом |
| `--radius` | 8px | | скругления |

Базовый размер 14px, заголовок страницы 22px, межстрочный 1.45. Плотность — рабочая: строки списка 11px по вертикали.

## Компоненты

- Навигация: Сегодня / Вакансии / Отклики / Профиль; Настройки внизу; постоянный переключатель кандидата и индикатор фонового поиска. Горячие клавиши ⌘/Ctrl+1…4 и ⌘/Ctrl+, . При ширине <1000px панель сворачивается до иконок (с `aria-label`).
- Значки статуса: «✓ Подходит», «? Уточнить», «✕ Не подходит»; жизненный цикл; этап; «ДЕМО».
- Вакансии: список слева (стрелки ↑/↓), карточка справа; фильтры по соответствию, этапу, источнику, жизненному циклу и типу; поиск; сортировка.
- Карточка: следующий шаг, таблица измерений (иконка, условие, жёсткость, причина, как выяснить, цитата со статусом факта), факты, текст объявления, источники/проверки/слияния/история оценок.
- Модальные окна с ловушкой фокуса, Esc и подписью; тосты в `aria-live`.
- `prefers-reduced-motion` отключает анимации; цвет никогда не единственный носитель статуса.
